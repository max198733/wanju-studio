# 代码动画素材快照

`skill-build/` 保留 2026-11-04 从 WorkBuddy 工作区交接的源素材：564 个文件，
包含目录索引、提示词、参考图片、公共函数和原始许可。构建不再依赖 WorkBuddy 的绝对路径。

在仓库根执行：

```sh
node tools/build-skills.mjs
# 或 pnpm styles:build
```

输出在 `packages/openfilm/skills-extra/`。生成 341 个独立风格目录，排序为 11–351。
源索引引用 193 张封面；`overrides/` 保留已有 K1、K2、K3 的封面，因此输出为
196 个带图条目和 145 个无图条目。缺图时保留文字展示，不制造风格预览。

生成器先校验全部输入，再写输出；重复构建结果一致。当前条目撤下封面或不再需要公共函数时，
清理对应生成文件，保留其他文件；不会删除目录索引之外的旧目录。
测试应使用 `buildStyles({ sourceDir, overrideDir, outputDir })` 的临时目录参数，
不要误把生产输出目录作为测试夹具。

## 源数据欠账

- M14、M15、M16、M17、M26、M35、M39、M40 缺少名称、摘要及有效提示词内容。
- V1–V15、X1–X31 有名称和正文，缺少目录摘要。
- 构建会报告这些条目，保留上游内容；不能把“341 个目录”描述成“341 个完整可用模板”。

## 许可与打包

原始许可和来源文件保留在快照内，并复制到输出的 `THIRD_PARTY/`，共 7 个文件。
逐项技能保留原署名和来源链接。合集包含不同来源，不能用项目 MIT 许可概括所有素材；
也不能单独计价或包装成付费技能销售。

`package.json` 的发布文件范围包含 `skills-extra`；桌面发布脚本同步刷新这一目录及
`THIRD_PARTY_NOTICES.md`。这些修改需在下一次桌面构建后验收新安装包；
源码构建成功不表示已更新用户机器上的安装版本。
