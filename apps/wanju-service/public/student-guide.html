1. 安装与升级

  1. 从官网 https://wanju.kukukaka.cn 下载 Windows 64 位统一客户端。请先保存并结束旧版本中的任务。
  2. 安装到自己的目录。安装包未代码签名，请遵守电脑安全策略，不要关闭防护软件。
  3. 旧工程继续保留。打开玩剧后可使用原生对话、时间线、预览与导出。本地功能不要求购买云空间。

2. 注册与登录

在官网“账号中心”或软件“账户与权益”中注册，账号 3–32 位，密码至少 10 位。统一账号注册不需要激活码。换电脑时使用同一个账号。

账号用于云项目、默认配置和平台账单；不会自动替你注册第三方平台。不要填写其他网站的登录密码。

开始对话创作

  1. 在“账户与权益”创建账号或登录。已开通服务时，默认基础档自动可用，无需额外启用。
  2. 回到对话，输入自己的制作要求，也可以附上参考图片或素材。登录、充值时未发送的草稿会保留。
  3. 聊天输入框旁可查看已开放档位的输入、输出和缓存价格，点选档位即切换；无需再次确认。制作过程中等待当前回合结束再切档。
  4. 每次模型请求按实际用量扣玩剧点；先预留，结束后退回多余点数。余额不足时请求不会发送，请先在账户页充值。
  5. 在预览和时间线检查成果，继续提出修改要求。

一次制作可能包含多次模型请求。不会自动升级到更贵档位；结果不明时先查看任务与账单，联系管理员核对，不要反复重发。

3. 图片、视频与音频配置

  1. 进入“设置 → 图片、视频与音频”。登录后自动同步账号配置，也可以点击“同步云端配置”。
  2. 每个类别默认选择“云端默认”。如显示未设置默认或未分配密钥，请联系管理员。
  3. 需要自有服务时点击对应类别“添加”，填写名称、协议、地址、模型和密钥，保存后在“服务来源”选择它。每类可保存多个供应商。
  4. 图片支持 OpenAI 兼容图片协议；视频支持 Seedance / 方舟与 H3 首帧协议。音频使用自定义 HTTP 服务，必须填写真实调用说明，不是只填模型名即可通用。
  5. 同步不会覆盖你的自定义选择。更换地址或协议必须重新填写密钥；已经提交的任务继续查询原供应商，不会自动重复生成。

“密钥已保存 · 未验证”仅表示配置存在。保存、同步不会发起付费请求；真实生成需自行确认费用。

4. 何导工作流与素材

在对话的技能入口启用“何导短剧工作流”，用新会话提出创作要求。按剧本、分镜检查、人物/场景/道具资产、分镜首帧、视频的顺序推进。先审核资产和首帧，再生成视频，能减少人物变化与返工。

“制作资产”查看人物、场景、道具与逐镜图片。图片只作参考，不自动进入时间轴；成功的视频按镜头绑定到原项目时间轴。失败或结果未知时先查询原任务，不要直接重发。

5. 保存云项目与换电脑

  1. 等待当前任务完成并保存本地工程。
  2. 进入“账户与权益 → 云项目”，选择本地项目，点击“保存到云端”。确认出现云版本保存成功。
  3. 在另一台电脑安装玩剧并登录同一账号，刷新云项目，点击“下载并打开”。软件校验真实文件并创建本地副本，不覆盖原工程。
  4. 同一个工程不要同时在两台电脑修改。版本冲突会阻止覆盖；请先核对并保留两个副本。

当前为手动同步，不是自动备份。首次每账号默认 1 GB，单文件最大 512 MB，管理员可调整配额。API 密钥和登录凭证不会跟随作品上传；第三方临时下载地址不等于永久云存储。

6. 历史版本、回收站与空间清理

  1. 在“账户与权益 → 账号云项目”点击项目旁的历史图标，选择版本下载。每次下载为独立本地副本；不会用旧版本覆盖云端最新项目。
  2. 点击垃圾桶并确认，将云项目移入回收站。本地工程不删除；回收站仍保留全部版本和素材，可以点击“恢复”。回收站不会自动清空。
  3. 需要永久删除时，在回收站点击“永久删除”并输入完整项目名称。全部云版本不可恢复；本地副本保留。旧副本不能重新上传到这个已删除编号，需另存为新项目。
  4. 点击“清理空间”，先查看可清理数量和大小，再确认。只回收没有被任何保留版本或回收站引用、且上传超过 24 小时的文件。每次最多 200 个；共享素材、近期上传和正在使用的文件保留。服务器备份时暂不允许清理。

7. 费用与常见故障

玩剧创作助手从玩剧点余额按已显示档位价格和实际模型用量自动结算，100 点对应 ¥1.00；当前通过充值码充值，未接入自动支付。选档前可查看输入、输出及缓存单价；切换立即生效，余额不足时不会发送模型请求。使用自有供应商时，由对应供应商单独计费。图片、视频与音频按各自显示的价格和服务设置计费；云项目成功生成服务费默认关闭，如开启会单独提示，重复同步不重复结算。

遇到黑屏、没有素材或慢：先查看当前项目、素材和任务状态。保留工程，提供版本、任务编号和错误截图；请勿发送密钥或密码。请求显示待核对时，对应点数暂留，管理员核对后结算或退回。
