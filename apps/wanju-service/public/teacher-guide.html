默认配置、云空间与收费管理

后台仅供运营人员使用。用户统一使用玩剧桌面端，通过自己的账号管理作品和余额。

1. 登录后台

访问 https://wanju.kukukaka.cn/admin，输入专用后台登录密码。用完退出；不把管理口令发给普通用户。修改登录密码不会改变数据库加密材料。不要更换服务器中的 WANJU_ADMIN_SECRET，否则旧密钥可能无法解密。

2. 设置默认供应商

  1. 打开“默认模型配置”，添加供应商名称、图片/视频/音频类别、接口协议、完整地址与模型名称。
  2. 图片使用 OpenAI 兼容图片；视频选择 Seedance / 方舟或 H3 首帧适配器；其他协议用自定义 HTTP 并填写请求、查询和结果处理说明。
  3. 为图片、视频、音频分别选择默认供应商，点击“保存默认配置”。全局模板不接收 API 密钥。
  4. 到“总览”的账户列表，点击对应用户“媒体密钥”，为该账号填写独立密钥并保存。留空保留，勾选撤销可删除。
  5. 用户登录后自动同步，也可手动刷新。已有自定义供应商和选择不被云端覆盖。

请分配该用户专用的第三方子密钥，切勿把运营者的主密钥分发给所有用户。凭证加密保存在云端，并在用户设备私有目录缓存供调用，界面不回显；拥有该设备控制权的人可能读取缓存。若需主密钥只留云端，须另做服务端生成网关。

修改供应商地址、协议或认证头会撤销对应账号的旧密钥，需要重新分配，防止密钥被发到新地址。保存配置不自动付费测试。

3. 云空间

“云项目与服务费”中可查看每个账号已用空间、配额并设置 GB 数。每个新账号默认 1 GB；配额不是自动购买服务器磁盘。用户在客户端手动保存云版本，在其他电脑下载恢复。

已用空间包含未完成同步所预留的完整文件大小。上传完成后转换为正式文件占用，不重复计算；超过 24 小时无活动的未完成上传进入定时回收队列。用户可查看历史、回收和恢复项目；永久删除需输入项目名称，再预览并清理未引用文件。回收站及历史版本不会自动清空；备份期间不执行空间清理。

当前使用单实例 SQLite 与持久卷，单文件最大 512 MB。账号配额不能替代服务器磁盘监控。关闭软件前未上传的修改仍只在用户本地。

4. 服务费与充值

默认关闭平台成功生成服务费，预设成功图片 5 点（0.05 元），视频 1 点（0.01 元）。开启后用户需单独确认云项目服务费；目前在保存到云端时按成功任务去重核算，失败任务不记成功收费。此费用独立于聊天助手的按量扣点及供应商直接收取的生成费用。

“激活与充值卡”支持人工收款后发充值卡：100 点对应界面 1 元余额，完整卡密只显示一次。没有自动支付；统一账号注册不再需要激活码。旧激活码和人工开通记录保留作兼容。

用户自带密钥和本地软件不是强制收费网关。正式收费前需真实小额对账、退款规则和试用验收，不可承诺离线不可绕过的即时扣费。

5. 创作档位与异常核账

  1. 在“创作助手”为每个档位分别设置供应商分组、接入地址、模型、密钥和单价。当前基础档使用 gpt-6.1-sol；增强档与高阶档只有完成对应上游验证并启用后才会向用户开放。新账号默认基础档。
  2. “填入截图双倍售价”可按成本估算填写输入、输出、缓存读取和缓存写入点价；100 点对应 ¥1.00。保存前核对供应商真实成本、缓存口径及舍入方式，运营后台显示的售价就是用户切换档位时看到的价格。
  3. 保存档位后点击“检查已保存线路”。系统只读取供应商的模型目录，不发送创作内容、不预留用户点数；若目录中找不到填写的模型，先修正模型名称或供应商分组，不要直接开放给用户。
  4. 线路检查通过后，再按供应商能力实测图片输入、工具调用和连续流式回复，勾选验证与启用并保存。切换上游模型后须重新核对接口协议、模型名称、工具调用、图片能力和返回用量；任一项不兼容时保持该档关闭。
  5. 已开放档位在账号登录后按当前显示的价格直接使用，不设聊天价格确认门槛。用户在输入框档位菜单查看单价，点选即切换；充值、选档和账户页清楚展示“按实际用量扣点”。已开始的请求按当时的价格快照结算。

对话主密钥仅留云端，不进入客户端。余额不足时预留失败，请求不会到达供应商，也不产生账单。超时或结果不明不会自动重发付费请求。“待核对请求”先对照供应商账单，再按请求编号结算或退回；缺少用量不猜测扣费。供应商故障时在后台切换已验证档位配置，不要让用户改填密钥；切换后先保存并做线路体检，再用模拟或获授权的小额请求验收。旧“学员开通”记录继续保留。

6. 发布、备份与恢复

发布前一致性备份数据库、云文件、服务器私有环境及旧版本。保留旧安装包以便回退，升级不删除用户工程。每天备份还需定期验证恢复，并做异地备份；同一云盘上的备份不能覆盖整机故障。

安装包当前未做 Windows 代码签名。原 MIT 许可与上游商标声明继续随源代码和安装资源保留。发布前核对版本、安装包校验值、下载清单与实际开放的服务，未开通的线路不要对外承诺可用。
