# 玩剧学员账户服务 0.1.1 内测

> 下文保留早期内测说明。当前工程与运营说明以 `docs/wanju/README.md`、`docs/wanju/账号云项目与按次服务费-需求与实施.md`、`docs/wanju/扣点与运营.md` 和 `docs/wanju/发布与运维.md` 为准。源码已加入统一账号、云项目文件/版本同步及可关闭的成功媒体任务服务费；仍需先部署并通过线上存储、备份、并发与对账验收。本轮未更新线上服务器。

这是 OpenFilm 原生编辑器的账户与运营服务。编辑器继续负责预览、时间线和导出。此服务源码可以运行云项目同步和图片/视频成功服务费原型；云项目文件保存在配置的持久化目录，收费默认关闭。公网服务、独立备份、在线支付和全供应商强制计费尚未完成。

## 本机试用

在桌面 `wanju` 文件夹双击 `打开老师后台.cmd`，会在本机启动 Node 服务、打开管理页面，并把管理口令放入剪贴板。将口令粘贴到登录框，不要发给学员。

后台生成激活码和充值卡后，双击 `打开学员内测版.cmd`。此入口将服务地址自动设为本机服务，数据使用独立目录，不读取原老师版的供应商密钥。

本机地址：`http://127.0.0.1:4890/admin`。本机模式只供这台电脑验证，不是学员异地可用的服务器。

本机依赖 Node.js 24 以上，以及现有工程中已安装的 Electron、构建文件。安装包本身不要求学员安装 Node.js。

## 数据与权限

- 数据目录：仓库 `.local/student-service/`；`wallet.sqlite` 保存账户、卡密摘要、账本和请求状态。
- `admin.key` 是后台口令，也是供应商配置的加密依据。备份时先停止服务，再把整个数据目录一起备份；不要只备份数据库而丢弃原口令。
- 供应商主密钥仅由老师填入后台并加密存储。学员程序持有其本人登录令牌，不接收供应商主密钥。
- 完整卡密仅在生成后显示一次，数据库只保存摘要和尾号。保存下载的卡密表，不要公开上传。
- 学员令牌保存在 Electron 主进程的系统加密存储中。会话退出、密码重置、暂停账户均有相应限制。
- 网关不把创作文本存入账本；实际生成请求仍会发送给老师选择的供应商。

## 计价规则

100 玩剧点对应学员端 1 元的标价。卡密面值是学员权益，不是自动收款记录，也不代表已实现利润。

输入和输出分别按实际用量结算：

`扣费点数 = 向上取整((输入Token × 输入售价 + 输出Token × 输出售价) / 1,000,000)`

售价单位为“玩剧点 / 百万Token”。当前不单独折扣缓存命中；同一供应商不同计费口径必须先核对账单。

后台要求单次预留不小于配置的最大上下文及最大输出所对应的费用。每次模型请求先预留、再按供应商返回的真实用量退回多余部分。一次创作可能调用多次模型。

网络中断、缺少用量、上游响应不完整时，系统保留预留并列入待核对，老师查上游账单后人工结算；不会自动重发付费任务。服务重启时，未完成请求也进入待核对。明确拒绝的请求按服务规则退回预留。

默认模型关闭、售价未填。只有老师填写上游地址/密钥/模型/售价，确认模型支持图片输入和工具调用后才可启用。这里的确认是老师对实际接口能力的确认，不会自动执行收费测试。

## 学员安装包

构建命令（仓库根目录）：`node apps/desktop/scripts/release-wanju.mjs`。

输出目录：桌面 `wanju/安装包/学员内测-0.1.1/`。保留原老师版 0.1.0 安装包。

`apps/desktop/student-service.public.json` 中只允许公开服务地址和学员版标记，不放任何密钥。目前公开服务地址为空，因此此包不能直接发给异地学员投入使用。本机内测入口通过环境变量提供本机地址。

部署好稳定的 HTTPS 服务后，将该公开配置的 `serviceUrl` 改为该地址并重建。学员随后只需安装、激活、登录、充值。当前包未做代码签名，属于内测产物。

## 托管部署准备

已提供 Dockerfile，可交给支持 Docker 和持久化磁盘的托管平台部署，无需自购服务器。当前没有创建云资源或绑定支付账户。

部署要求：

1. 镜像构建目录为 `apps/wanju-service`，运行 Node.js 24，监听平台指定的 `PORT`，`HOST=0.0.0.0`。
2. 设置长度至少 32 的随机 `WANJU_ADMIN_SECRET`，作为平台私密环境变量保存。不要提交到仓库。
3. 挂载持久化磁盘至 `/data`，`WANJU_SERVICE_DB=/data/wallet.sqlite`；确保容器内 node 用户可写。
4. 由平台提供 HTTPS 域名。不要把管理口令写在网址或公开配置里。
5. 先只开一个实例。SQLite 当前按单机单库设计，不能简单横向扩容或在无持久盘的函数里运行。
6. 先用模拟账户和模拟上游跑验收，再由老师明确授权真实模型的小额测试预算，核实账单。

本地 Docker 测试示例（先在当前终端中安全设置 `WANJU_ADMIN_SECRET`）：

```powershell
docker build -t wanju-students apps/wanju-service
docker volume create wanju-students-data
docker run --name wanju-students --restart unless-stopped -d -p 127.0.0.1:4890:4890 --env WANJU_ADMIN_SECRET --mount source=wanju-students-data,target=/data wanju-students
```

该命令仍只开放本机端口，不等于公网部署。

- 为图片、视频、音乐建立独立异步任务账本、查单、结算和失败退回，再接原编辑器。
