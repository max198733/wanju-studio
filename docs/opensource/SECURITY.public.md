# Security

Wanju runs a local editor and can read and write the projects you open. Provider credentials belong in local
configuration or environment variables, never in issues, pull requests, screenshots or exported projects.

Use this repository's private vulnerability reporting feature when it is enabled. If it is unavailable, open an
issue asking for a private contact channel without publishing the vulnerability, credentials or personal data.
This independent adaptation is maintained separately from OpenFilm; do not send Wanju-specific operational reports
to the upstream project's support address.

The 2.1.0 signed release is pending. A successful source build, checksum or GitHub artifact is not proof of a
trusted Windows signature. Verify the release's signing report and Authenticode publisher.

Cloud sign-in, cloud transfers and external AI services send data to their selected endpoints. Local editing and
export do not require uploading a project. Review the selected service's policy before sending content.
