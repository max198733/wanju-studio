# 玩剧配置与账户专项审查

## 原生职责

OpenFilm 原生将三个系统分开：本地编辑与导出、对话智能体、图片与视频供应商。
前两类外部服务使用各自的账户或密钥。本地编辑不依赖登录。
玩剧增加的学员账户是云端余额账户，不等同于第三方平台注册，也不等同于老师本机的 API 密钥。

## 确认的问题

| 级别 | 问题 | 处理要求 |
| --- | --- | --- |
| P1 | 云端统一钱包的图片、视频扣费接口尚未接通 | 明确展示未开通，不复制老师密钥或假装解锁；自有服务单独授权 |
| P1 | 登录失效后页面可能继续显示旧余额及已启用状态 | 失效清理、通知全部窗口，离线不得显示权益已确认 |
| P2 | 图片配置重复列出，隐藏名称后的线路无法区分 | 每项能力只出现一次，按用途命名 |
| P2 | 有密钥就显示绿点，尚未实现的线路也显示已配置 | 区分密钥已保存、未验证、尚未接入、当前版本不支持 |
| P2 | 老师本地配置和学员云端账户混在通用页 | 独立账户与权益、创作助手、图片与视频入口 |
| P2 | H3 只能导入文件配置，和另外两项的操作不一致 | 增加本机密钥表单，保留高级导入 |

## 交付规则

- 老师版：可配置自己的对话及媒体密钥，供应商直接扣费，不消耗学员点数。
- 学员版：账户、价格确认和余额决定云端助手可用性；不显示老师密钥。激活登录后可主动启用自有媒体服务并配置自己的密钥，直接向供应商付费。
- 本地剪辑、素材导入和导出在登录前后均可使用，这是明确的产品规则。
- 云端图片、视频、音乐仍未开通，不能因登录或激活显示可用。
- 何导工作流是随软件安装的创作规则，不是视频生成服务或充值权益。
- 保留上游许可证与必要法律声明文件，公开设置入口使用玩剧品牌。

## 使用入口与剩余限制

老师使用“设置 → 图片与视频”填写本机服务密钥，不要求激活。
学员使用“账户与权益”激活或登录，再到“图片与视频”主动启用自有服务，填写自己的密钥。
图片、视频配置按学员账户分目录保存，切换账户不会自动继承上一人的自有服务选择。
自有服务由供应商直接扣费，与玩剧点和云端创作助手计费分开。
首帧视频涉及本地图片上传时，仍需高级配置中的配套素材存储配置。

测试没有购买或生成任何图片、视频，不能由此断言供应商当前可用或成片人物一致性已通过。
云端统一媒体代理、媒体钱包扣费、线上整套激活回归，以及真实付费出片仍需后续验收。
旧任务缺少项目和分镜校验信息时，保留已经下载的文件，不自动挂入新分镜，可核对后手动导入。
已有对话的工作目录不会随标签切换而改变；工作流要求所有后续操作显式使用新项目 ID。
用户测试新故事时应在相应新项目发起新对话，不在旧广告对话中混用原生编辑命令。
