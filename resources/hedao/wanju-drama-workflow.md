# 玩剧短剧连续性流程：Seedance 2.0

适用范围：60–180 秒的单集短剧。本篇是何导工作流在玩剧中的执行补充，不取代已经验证有效的“小说/故事 → 剧本 → 分镜 → 资产 → 分镜图 → 视频”顺序，也不改写原始何导文件。按当前阶段读取何导规则，并参考本篇与 `video_seedance` 接口合同。工程仍使用 OpenFilm 的预览、时间轴和导出。

## 质量目标与边界

不能承诺模型绝不换脸、手部绝不变形或任意动作都准确。程序能锁定参考和连续性信息、拦住跳阶段、保留任务与审核记录；人物是否像、动作是否自然仍须查看真实视频。相同随机种子不是人物身份锁。提高分辨率也不能替代身份参考和分镜设计。

## 1. 故事先闭环

先保存真正的剧本：目标、阻碍、转折、结尾，以及每段推进的故事事实。默认先用 1–3 位角色、1–2 个主要场景、一套主服装，减少无必要的跨时空切换。

以 8–12 秒为一个主要生成单元，单元内可以是一个完整动作或一小段对话；需要时用 4–6 秒反应镜头。不要强制每 5 秒重新描述和生成一遍人物，也不要一次请求 1–3 分钟。60/120/180 秒可先按约 6–8/12–16/18–24 个单元设计，再按故事调整，单次请求始终遵守接口的时长范围。

每个单元必须记录：镜号、故事节拍、在场角色、场景、开始状态、核心动作、结束状态。状态明确持物的手、服装/伤口/道具变化、人物相对位置和视线方向。相邻单元检查因果衔接，禁止只写“保持一致”。

## 2. 锁定人物与场景资产

每位人物设稳定 ID 和固定外形描述。人物身份图优先用独立的人脸特写，另用单人全身照锁定妆造，明确各图的用途和同一人物的对应关系；不要把多视图拼图当成身份图，不要混入多个版本。场景和关键道具也有稳定 ID、描述和独立参考图。

人物/场景参考必须是实际导入或成功生成的本地图片，不能是空目录、待生成文件名或文字占位。修改角色外形或更换参考图后重新审核。不要把上一镜生成后已经变形的人脸当成下一镜唯一的身份来源。

官方渠道对人像素材有额外接入与授权要求时，先核对账号当前能力和官方人像资产方案；不要绕过服务端的人像限制，也不要承诺普通图片引用一定可用于真人。

## 3. 程序绑定逐镜参考

启用何导资产闭环后，资产清单及逐镜绑定保存在 `.film/wanju-assets.json`。每个镜头关联人物、场景和关键道具的资产 ID。程序据此组织稳定参考，不能让 AI 在某一镜忘记传参考。分镜仍存入原有 board，参考图片只做素材，不进时间轴。

实际工具顺序为：`assets` 读取 → `save_assets` 登记计划和绑定 → 授权后 `generate_asset` 逐项生成 → 查看图片并记录资产审核 → `generate_image` 生成带参考的分镜图 → 查看图册并通过 `save_assets(approve_storyboard:true)` 记录审核 → `generate_video`。参数以 `tool_contract` 为准。独立人物、场景、道具图片不伪装成分镜。每次修改使用最新的分镜版本和资产清单版本。

图片在 `assets/characters`、`assets/scenes`、`assets/props` 保存原件，并分别归档至 `02-角色/01-定妆照`、`03-场景/01-场景图`、`04-参考素材/01-道具`；分镜图归档至 `08-分镜静态图`。编辑器右上方“制作资产”显示实际文件、审核状态和逐镜图片。旧成功任务丢失图片关联时，使用 `recover_assets` 恢复，不能重新付费生图。

提示词固定顺序：参考编号与身份映射 → 本镜起始状态 → 一个主要动作/对话 → 景别、机位和视线 → 结束状态 → 声音。优先明确的正向约束，避免不断叠加很长的负面词、夸张运镜和多人复杂交互。

跨镜延续以主参考为锚；必要的上一镜视频仅作为补充，并且必须先验收。不要整片递归依赖上一镜尾帧，否则误差容易被逐镜继承。当前适配器的 `returnLastFrame` 只是请求返回尾帧，不能把它当成程序已接入首尾帧控制。

## 4. 两镜试拍，再批量

先选择两个代表性单元：一个人物近/中景，一个同角色换机位或行动后的镜头。授权范围明确为这两个视频任务；未确认成本前只做免费规划。

必须查看实际视频，而不只是首帧或缩略图：脸与发型、服装和道具、手部和接触动作、人物站位与轴线、前后动作状态、对白与声音。记录发现的问题，不得为过关而把失败结论改成通过。通过后再按 2–3 个单元一批推进，每批验收后继续。

剧本审核、参考审核、连续性审核和试拍审核应绑定当前制作计划及分镜版本。修改剧本、参考或镜头内容后，旧审核不能自动沿用。工具校验的是结构、文件和审核记录，不是假装自动识别人脸。

## 5. 声音策略要先选

对人物声线要求高时，推荐先完成视频，再使用同一套配音资源统一配音；本软件不能把尚未接入的 TTS 服务说成已能自动配音。也可使用模型原生音频，但要提供一致的说话人要求/合规参考，并在两镜试拍时实际验收声线。每镜各自凭文字生成声音可能不一致。

不要让成片原声重复叠放。音乐做单独音轨，剪辑时检查人声清晰度、响度与峰值。没有配音或对白未对齐时，明确标记为待配音版本。

## 6. 成功即入轴，失败只修本镜

只有真实生成并下载成功的视频进入原生时间轴一次；图片、占位卡和未完成任务不进轴。逐镜显示成果，不必等全片结束。继续沿用现有 OpenFilm 手工编辑、锁定和覆盖逻辑。

付费台账以工具保存的任务为准。提交结果未知时只核对原任务，不自动重发。验收失败只记录并提出本镜修订，不未经授权把整集重做。
