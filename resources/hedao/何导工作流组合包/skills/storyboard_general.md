# 通用分镜技能

> 技能键：`embedded_skills.storyboard_skill_general`　|　来源：何导工作流 v1.24.33
> 调用时机：**需要时才加载本文件**；工作流骨架只保留指针，不内联本文件正文。
> 单源规则：本文件是该技能的唯一真源；骨架、其它技能、闸门均只引用不复制。


## 最高优先规则：全量通读 · 禁止抽样（v1.24.38 / FPR-1）

> 本规则压过本技能其余一切写法要求。真源：`standards/full_pass_review_policy.json`。

写卡与查卡时一律**从头到尾逐镜过，禁止抽样**：

1. **不许抽检**：不按比例抽、不只看前 N 镜、不只看导演点名的那几镜、不以「其余镜差不多」为由跳过。卡里有 N 镜就查 N 镜。
2. **每镜回读前后各 3 镜**，逐项对照：时间与光影／场景与参照物／站位与层位（谁在前景、谁在后景、谁在画面左、谁在画面右）／朝向与视线／入画名单／动作接力／服装形态／道具链／构图接力／景别趋势。
3. **换时间面必须整体换挡**：转场镜落点之后的所有镜，光影段落一起换；同一场景 ID 的光影用词必须与该场景 `time_lighting_lock` 一致（夜锁写晨光、晨锁写夜景都是 P0）。
4. **转场镜起帧复刻上一镜**：同一场景内的时间转场，机位、景别、构图必须与上一镜完全一致；跨场景大转场则必须换构图。
5. **静与动分开核对**：人是站着还是坐着、手在哪、脚在哪、重心在哪，必须逐镜复述，不许只写「姿态不变」。
6. **发现一镜错，回扫全卡同类问题**一起改；只修点名镜视为未完成。
7. **交付写「已全量检查 N/N 镜」**，写不出分子分母的视为没查。

机检：`STG4-C31 跨镜上下文一致性`（场景时间锁↔光影、转场起帧↔上一镜机位景别，逐镜全量）。

## 拆镜执行总纲（三套分镜共用·最高优先级）

> 本块由 `_tools/pack_build.py` 从真源 `standards/storyboard_execution_framework.json` 渲染注入；
> `skills/storyboard_h3.md` / `skills/storyboard_general.md` / `skills/storyboard_seedance25.md` 三份文件顶部的本块内容逐字一致。
> **动手拆镜前必须先完整读完本块**，本块优先级高于本技能其余所有条目。
> 本块内的名称与数值一律逐字取用：禁止凭记忆、禁止自创、禁止用近义词替换。

### 一、唯一工序：九步（顺序不可调整、不可跳过、不可合并）

- **开工前置**：任何一次拆镜开工前，必须完整读完本键，再读本技能其余条目与 standards/*.json；未读完本键禁止开始写作、禁止直接进镜头。
- **第0步 路由**：读 embedded_skills.storyboard_skill_router，按 video_engine（seedance 项目再看 seedance_model）选定唯一一套分镜技能，路由结果写入 13-工作流文档/阶段状态.json 的 stage4 记录。三套互斥：禁止混用、禁止叠加、禁止凭习惯默认用 H3 分镜。
- **第1步 通读剧本**：读 stage3 剧本全文，逐场景通读，标出每个场景的在场人物（含无声在场人物）与每个场景的叙事节拍（环境建立 / 人物聚焦 / 新人物新道具登场 / 关键场景切换 / 对话交锋 / 动作冲突 / 情绪转折）。
- **第2步 锁场景**：为每个场景建场景人物清单、登记唯一 scene_id；选定参照物、锁定全员总体站位（scene_blocking_policy）；存在双人面对面对话的场景登记正/反面与面ID映射，并完成组级『说话人→场景面资产』绑定。
- **第3步 先出框架**：在写任何镜头内容之前，先把 mandatory_format_rules 规定的【整体分镜固定格式框架】完整输出（overall_soundscape + 逐个镜头组标题 + 逐镜字段空壳）；框架未输出，禁止开始填内容。
- **第4步 定组类型**：按 shot_group_closed_set_rule 为每个叙事节拍选定唯一的组类型（只能取六类之一），逐组写明『组类型：X | 叙事目的：Y』；选型必须拿出该组类型的 application_scenario 作依据，禁止凭手感、禁止自创。
- **第5步 定组内结构**：在组内按该组类型的 structure_match 定镜数与景别序列：**一组的镜数由「把这件事讲明白」决定，不设数量上限**（旧「每组 1 主镜头 + 1-2 次镜头、总 1-3 镜」的数量上限自 v1.22.0 废止）；正反打组上限=该段说话人数（说话人台词超 15 字须补 1 个对方表情反应镜，反应镜不计入上限）；战斗组核心 4 环节不变、可在任意位置插入 1-2 镜（总 4-6 镜）；**组内相邻两镜景别不得相同**（正反打 / 连续整体展示 / 连续细节展示三类豁免）；禁止超出该组类型的景别约束。
- **第6步 定运镜**：按 camera_movement_closed_set_rule 为每镜选运镜（只能取**六类**之一：固定运镜 / 水平·垂直展示运镜 / 拉近运镜 / 拉远运镜 / 环绕运镜 / 跟拍运镜，逐字照抄），**并写明运镜起点与终点**（固定运镜写「固定运镜」即可；其余五类必须写清起于什么、止于什么，跟拍还须写明焦点是谁）；且该镜内容必须落在该类运镜的 application 适用范围内；同时满足反单一化硬约束。
- **第7步 写画面内容（v1.24.31 强化）**：逐镜写画面内容：景别决定信息粒度（大景别写整体、小景别写细节）；**画面内容三要素必写——①人物行动轨迹（从哪到哪、路径起点与终点）②动作细节（发力部位、幅度、速度、接触点）③神态细节（面部、眼神、呼吸、肢体的可观察状态）**；**神态不得只写情绪标签**（『愤怒』『悲伤』『惊讶』这类词不得当神态描写交差），近景/特写/大特写**必须写到五官怎么动**（眉峰上挑／眉心竖褶／眼睑收窄／瞳孔收缩／鼻翼翕动／嘴角一侧下拉／咬肌鼓起／喉结滚动／眼眶泛红…），情绪词只能作为五官描写之后的补充说明；**镜头内有几个人就挨个写每个人**（各自的动作·位置·神态至少各一处），禁止只写主角、禁止用『两人相视一笑』这类合并句替代逐人描述；**画面内道具发生状态变化必须写清变化前→变化后**并写明触发者；**写详细 ≠ 写不入画的人或物**：画外人物、前情、心理活动、后续剧情、场外声一律不写进画面内容；景别为特写时开头先写 焦点：[焦点对象]（[该对象在本镜的具体可见状态]）；转场镜在开头先写 `转场镜：[类型]｜`；有出场人物逐人写明眼神/视线落点（禁止看向镜头）；存在压抑/伪装/隐忍/矛盾情绪时按微表情系统写时序化可观察微动作。详见 standards/frame_description_detail_policy.json。
- **第8步 回填场景与人物**：画面内容写完之后，再回填『场景与人物』栏：画面出现几个**有名角色**就写几个（**无名环境人群 extras 不计入本栏**），逐人带 asset_id、画面出现的场景带 scene_id、正反打/过肩带面ID，**并同栏并列写明本镜站位子格式**（见 scene_blocking_policy.per_shot_blocking_format）；禁止先写本栏再倒推画面。
- **第9步 自检与过闸**：逐条执行本技能 self_checks 与 stage4 self_checks，再运行 stage4 闸门脚本；闸门未 PASS 之前，禁止写入 06-分镜/02-场次分镜卡、禁止标记 passed、禁止进入 stage5。

> 上述九步是唯一合法工序：顺序不可调整、不可跳过、不可合并。禁止在未通读剧本、未锁场景站位、未定组类型的情况下直接开始逐镜写作。

> 分镜卡以『镜头组』为组织单位，不以剧本场景/场次为单位。『场次』（剧本场景段落）与『镜头组』（shot_group）是两个不同概念：禁止把场次、剧情段、段落当作镜头组，禁止给场次或场景段落冠以『镜头组』标题。

> 组类型、景别、机位、运镜四类字段全部是闭集：取值只能逐字取自工作流给定标准，禁止自创、禁止自造变体、禁止用近义词或复合名。

### 二、格式强制要求（重点：『场景与人物』栏）

> 分镜格式是硬约束，不是建议。除『台词』项按有无台词条件出现外，字段名称、字段顺序、字段数量一律不得增减、改名、调序、拆分或合并。

**顶层与组标题**

- overall_soundscape：（全局环境音效 / 背景音，无 BGM；全片只写一次，不散落到各镜）
- 镜头组 X（组类型：<六类闭集之一，逐字照抄> | 叙事目的：<单一叙事目的>）

**单镜字段顺序（逐镜一致，顺序即下列顺序）**

1. 镜号：
2. 持续时长：
3. 机位：
4. 景别：（远景 / 全景 / 中景 / 近景 / 特写 / 大特写，必填独立字段，与机位并列）
5. 光影：
6. 场景与人物：
7. 画面内容：
8. 运镜方式：
9. 音效：
10. 台词：（仅该镜有台词时出现；无台词时整项省略，不写空值、无、无台词或任何占位符）

> 字段顺序即上方顺序，逐镜一致；本清单与 standards/storyboard_specification.json 的 fixed_fill_in_format 同源，禁止自行增删字段。

**『场景与人物』栏·五条硬规则**

- **priority**：【画面内容优先·硬规则】本栏必须在本镜『画面内容』写完之后，按画面内容推导回填：先写画面讲了什么，再据画面实际出场的人物与场景写本栏。禁止先写本栏再编画面，禁止拿场景人物清单整抄，禁止凭空预设人物清单后倒推画面。
- **count（v1.24.15 修订）**：画面内容里出现**几个有名角色（CHxx）**，本栏就写几个：不多写、不漏写、不写未入画角色；本栏有名角色数量必须与画面内容实际出现的有名角色数量逐一对应。**无名环境人群（extras：无姓名 / 无台词 / 无独立人设的路人、队列、围观者、背景人流）不计入本栏、不占单镜 ≤3 人上限**（见 scene_character_roster_policy 的 per_shot_character_cap.extras_rule）；人群只在『画面内容』中按环境元素描述。
- **character_id**：每个出场人物一律写成『角色正式名（asset_id）』，如 耶耶（CH01）、林盏（CH02）；禁止只写角色名、禁止用简称别名或称号、禁止临时编号。
- **character_form（角色子形态，v1.23.0）**：使用**非基底形态**时写成『角色正式名（CHxx_Cnn）』（如 林晚（CH01_C02））；使用**基底形态**时写『角色正式名（CHxx）』（等价于 CHxx_C01）。**同一镜同一角色只能写一个形态**（禁止同一镜同时出现 CH01 与 CH01_C02、或同一角色的两个子形态）；形态切换必须在『画面内容』中有明确着装/造型描述。真源 standards/character_sub_form_policy.json。
- **scene_id**：画面中出现的每个场景一律写成『场景正式名（scene_id）』，如 便利店收银区（SC01）；禁止只写场景名不写 ID。
- **blocking（站位，v1.24.15 新增）**：本栏并列写明本镜站位，固定子格式 **『站位：参照物【参照物名】｜角色A（CHxx）［方位］、角色B（CHxx）［方位］』**；方位取值逐字取自 scene_blocking_policy.per_shot_blocking_format 的**九项方位闭集**（参照物左侧 / 参照物右侧 / 参照物正前方 / 参照物后方 / 参照物前景 / 参照物背景 / 画面左缘 / 画面右缘 / 镜头外原位），**禁止自造方位**；同一场景参照物自始至终唯一；未发生走动的镜与场景锁定初始站位逐字一致；任一角色走动后，**下一镜整体更新全员方位**（不得只更新走动者）。站位一致性由 stage4 闸门机检（真源 scene_blocking_policy 的 scene_blocking_anchor_rule）。
- **face_id**：正反打 / 过肩镜头必须再写明场景拍摄面与面ID，写成『场景正式名·面名（面ID）』，如 便利店收银区·背面（SC01_B）；过肩镜头还须写明『过[肩主角色名]的肩拍[被拍角色名]』，**且本栏必须同时列出肩主与被拍者两人（各带 CHxx）**——肩主虽为背影前景但同样出镜，**必进栏、必绑参考图**（v1.24.17；否则背影人物不绑参考会错乱）。面ID按画面视觉中心正脸人物归属：拍A正脸=正面 SCxx_F，拍B正脸=背面 SCxx_B。
- **binding**：本栏人物集合 = 该镜 visible_character_asset_ids = 下游 stage6 分镜图与 stage7 视频绑定人物的唯一依据，三者必须完全一致。
- **face_schema（v1.21.29·场景面映射唯一结构）**：场景面映射一律写进场景人物清单该场景条目的 `face_split` 字段，六键齐全——`front_face_id`（正面面ID，SCxx_F）、`back_face_id`（背面面ID，SCxx_B）、`face_owner`（键严格为这两个面ID，值为该面被拍正脸人物『角色正式名（CHxx）』，两面必须归属不同人物）、`camera_direction`（键与 face_owner 完全一致，值为该面机位方向，二者必须互为反向）、`group_binding`（该场景每个正反打/过肩组一条：{group_id, group_no, group_type, speakers, binding}，binding 的键逐字取自 speakers，同一说话人在同场景所有组内必须绑同一个面）、`note`（写明哪些场次用面拆分、哪些镜头只沿用基础场景ID）。两面ID必须与 scene_id 同源（SC02 → SC02_F / SC02_B）；不需要面拆分的场景显式写 `face_split: null`。**已废止** `face_mapping` 与中文字段『正面／背面／归属规则／机位方向』写法。面资产文件名与面ID逐字一致（`SCxx_F_v{n}.png` / `SCxx_B_v{n}.png`，模式 `{asset_id}_v{version}.png`），两面必须成对生成，缺任一面即阻断 stage6/stage7；详见 shot_reverse_shot_scene_face_policy 的 face_schema / scene_asset_naming_rule / scene_asset_contract。
- **prop_id（道具ID，v1.21.31）**：『画面内容』中出现的道具，凡属**贯穿全剧的道具**（全片反复出现、承载剧情线索/伏笔/关键动作/信物的道具，如天平、相框、直播手机），一律在本栏标注道具ID，写成『道具正式名（PRPxx）』（如：古铜天平（PRP01））；**只出现一两次的过场道具不标注、不生成资产、不参与参考绑定**（避免多参膨胀撑爆单镜上限）。同一道具在不同镜中必须使用同一 PRPxx，禁止同物异号、同号异物；道具ID全片唯一，与 stage5 资产生成、stage6 分镜图绑定、stage7 视频 ref_image 共用同一套编号。
- **single_source_chain（单源参考链，v1.21.31·强制）**：本栏是全片参考绑定的**唯一数据源**，链路单向、不可跳级、不可反向覆盖：**『画面内容』（先写）→ 『场景与人物』栏（据画面反写，依次含人物 CHxx（用非基底形态时写 CHxx_Cnn）／ 场景 SCxx（正反打带面ID）／ 道具 PRPxx）→ stage5 按栏内 asset_id 生成资产 → stage6 分镜图按栏内 asset_id 绑定参考图 → stage7 视频按同一栏绑定 ref_image 与 <Subject N>**。**本栏出现什么，下游就必须参考什么——一个不多、一个不少、顺序一致**；任何一环都不得自行增删、换绑或跳过本栏直接凭剧本/清单猜绑定。本栏漏写（该带ID却没带）即视为该镜不合格，回 stage4 返修，禁止在下游自行补ID。

**『场景与人物』栏·明确禁止**

- ⛔ 禁止只写站位不列人物
- ⛔ 禁止站位漂移（v1.24.15）：同一场景参照物不一致 / 未走动却改变方位 / 走动后只更新走动者一人 / 使用方位闭集以外的自造方位词
- ⛔ 禁止写入画面中未出现的人物或场景
- ⛔ 禁止把场景人物清单的全体在场人物整抄进单镜本栏（清单是场景级、本栏是镜头级，两者必须分开记录）
- ⛔ 禁止无 ID、用别名或临时编号
- ⛔ 禁止本栏与画面内容出镜内容不一致

**『画面内容』八条**

- **continuity（承上启下结构已废止，v1.24.17）**：『画面内容』**不再写 `承接：` / `尾帧：` 标记**，直接写本镜画面本体描述（三要素 / 景别粒度 / 特写焦点 / 眼神落点 / 微表情仍照常）。**废止理由**：承接段须逐字复用上一镜 `尾帧：`，会把**上一镜的人物 / 道具 / 场景名**带进本镜文本，而分镜图与视频提示词**逐字包含『画面内容』**，模型可能据此在本镜画出上一镜的人物，多参却只按『场景与人物』栏绑定 → 造成画面人物错乱。跨镜连贯性由「站位锁定 + 动作三阶段 + 组间状态衔接」承担。真源 standards/storyboard_specification.json 的 shot_content_continuity_rule（已废止条）。
- **granularity**：画面内容的信息粒度必须与景别严格匹配：大景别（远景 / 全景 / 中景）写整体；小景别（近景 / 特写 / 大特写）写细节，且必须落实为具体细节描写——人物小景别写五官神态 / 眼神 / 呼吸 / 手部与局部肢体，场景小景别写环境局部特征与质感，道具小景别写材质纹理状态；禁止景别写特写而画面内容仍是场景全貌。
- **closeup_focus**：景别为『特写』的镜头，画面内容**开头**必须先写本镜唯一焦点，格式 焦点：[焦点对象]（[该对象在本镜的具体可见状态]）；唯一、具体、落在画面视觉中心，禁止泛指（人物 / 道具 / 环境 / 表情）与多焦点并列。
- **eye_line**：有出场人物的镜头必须逐人写明眼神/视线落点；任何角色一律禁止看向镜头/屏幕/观众（除非该镜已标注用户授权并在阶段状态.json 记录 eye_contact_camera_authorized=true）；无人物镜头写『画面内无人物，无眼神要求』。
- **micro_expression**：存在压抑 / 伪装 / 隐忍 / 矛盾情绪的小景别镜头，按微表情系统写时序化可观察微动作（baseline→leak→suppression→可选升级或复位→after_state）；禁止纯心理形容词，禁止并行堆砌五六个以上微动作。
- **no_dialogue_words**：画面内容中绝对禁止出现说话、台词、对白、开口讲等字眼（有台词时台词写进『台词』字段，不写进画面内容）。
- **three_elements（v1.22.0 强制）**：**有出场人物的镜头，画面内容必须写清三要素**——①**人物行动轨迹**（人物从哪到哪、沿什么路径位移，写明起点与终点）；②**动作细节**（动作如何完成：发力部位、幅度、速度、与道具或他人的接触点）；③**神态细节**（面部／眼神／呼吸／肢体的可观察状态，小景别镜必写、大景别镜写视线朝向与姿态级别）。三者缺任一即判该镜不合格。
- **transition_marker（v1.22.0）**：若该镜为转场镜，**在画面内容开头**写 `转场镜：[转场类型]｜` 标记（类型取 遮挡物穿越转场 / 位移物遮挡转场 / 物体不变·场景变换转场，见 standards/transition_shot_system.json），再接焦点标记与正文。
- **group_gap_detail（组间细节镜，v1.24.21，P0）**：全片**每相邻两组镜头之间必须插入一个细节镜**，景别固定为**大特写**，内容为**人物细节**或**场景细节**二者之一——人物细节＝面部五官（眼/眉/唇/睫）、眼神、呼吸、咽喉、手部、局部肢体的极细微可观察状态；场景细节＝环境某一局部的特征与质感（墙皮剥落纹路、门槛磨损、器物磕口、窗纸透光、水面涟漪、地砖裂缝等）。该镜为**独立组间镜位**，不属于前后任何一组、不计入任何组的镜数与景别趋势；组数 N 时细节镜数量**恰好 = N**（每组收束之后各一个，不少不多；某组塞两个、别的组没有同样不合规）。写法：『画面内容』开头标注固定标记 `组间细节镜：[人物细节|场景细节]｜`，再接 焦点：[细节对象]（[可见状态]）；细节对象必须取自相邻两组中已出现的人物或场景，禁止引入新人物/新场景/新道具；含人物面部的细节镜仍受 character_facing_policy 人物朝向硬规则约束（局部可写『面部不入画』）；纯场景细节镜属无人物空镜，不写眼神落点。真源 standards/group_gap_detail_shot_policy.json。

### 三、镜头组形式：全片只能用这六类

> 全片每一个镜头组必须且只能取上述六类之一（真源 standards/shot_group_types.json）；组类型名逐字照抄，禁止自创、禁止混搭、禁止自造简写变体（不得写成『拉近组』『特写组』『对话组』『动作组』『空镜组』等）。

| 该组的叙事目的 | 只能用的组类型（逐字照抄） |
|---|---|
| 先给核心细节、再向外交代整体环境与人物时空位置 | 从小到大（环境展开逻辑）——**首镜小景别、末镜大景别**，中间可回摆；镜数由讲清一件事决定 |
| 先立整体场景 / 人物完整状态、再落到关键细节 | 从大到小（焦点聚焦逻辑）——**首镜大景别、末镜小景别**，中间可回摆；镜数由讲清一件事决定 |
| 全新人物登场、关键道具首次亮相 | 连续细节展示（新人物 / 新道具专属）——3 镜标配，组内只能近景 / 特写；豁免景别相邻约束 |
| 剧情高潮 / 重大转折 / BOSS 对战场地 / 主角进入全新环境 | 连续整体展示（关键场景专属）——2-3 镜全景 / 远景同级；豁免景别相邻约束；普通日常场景切换禁止使用 |
| 两人及以上同场景持续对话、交涉、轮流发言 | 正反打（对话切换逻辑）——同景别单人镜逐镜跟随说话人，上限=该段说话人数（说话人台词超 15 字须补 1 个对方表情反应镜）；需先在前镜建立说话人位置关系 |
| 技能释放 / 打斗交锋 / 法术对轰 / 近身战 / 受击反应 | 战斗组（动作交锋逻辑）——核心 4 环节（发动→特效→命中→反应）不变、可在任意位置插入 1-2 镜（总 4-6 镜），特效环节所在镜景别必须为特写 |

> 选型必须逐组写明依据：先判定该组承担的叙事目的，再据上表取对应组类型；禁止凭手感选型、禁止一组承担多个叙事目的、禁止在同一组内混搭两种组类型。

- **反单一化（硬约束）**：禁止全片只用一种组类型。两条硬约束：①全片使用的组类型种类数 ≥ min(3, 全片镜头组总数)；②单一组类型占全片镜头组总数的比例 ≤ 60%。
- 为什么：六类组分别承担环境建立、细节聚焦、人物登场、关键场景、对话交锋、动作冲突六种叙事职能；只用一种组类型等于放弃其余叙事职能，全片节奏必然单一。
- 怎么查：统计全片各组建的组类型分布：种类数与单一组类型最高占比；任一超限即整体不合格 needs_revision，统计明细写入 06-分镜/01-分镜管线/分镜总时长统计.json 的 group_type_distribution 块。
- 组内镜数与景别约束——**镜数由「讲明白一件事」决定、不设数量上限**；正反打组上限=说话人数（+长台词反应镜）；战斗组 = 核心 4 环节 + 可插入 1-2 镜 = 4-6 镜；连续细节展示 3 镜标配；连续整体展示 2-3 镜——逐字取自 standards/shot_group_types.json 的 structure_match；**「组内相邻两镜景别不得相同」（三豁免：正反打 / 连续整体展示 / 连续细节展示）** 逐字取自 standards/shot_scale_standard.json 的 adjacency_rule；禁止自定。

### 四、运镜：全片只能用这六类，且必须落在适用范围

> 所有镜头的『运镜方式』字段只能填上述**六类**之一的名称（真源 standards/camera_movement_system.json），逐字照抄（含空格与斜杠，比对前先做空白归一）；**每类运镜必须写明运镜起点与终点**（固定运镜写「固定运镜」即可，其余五类写清起于什么、止于什么，跟拍须写明焦点是谁）；禁止自创运镜名（『缓慢推近』『快速跟拍』『平视推进』『缓慢摇镜』『希区柯克变焦』『穿越障碍物运镜』『水平平移运镜』一律非法）、禁止写复合运镜名（如『拉近+环绕』『平移推近』）、禁止留空、禁止缺运镜项目、禁止用机位或景别顶替运镜字段。

| 运镜（逐字照抄） | 只用在这些镜 |
|---|---|
| 固定运镜 | **全片主用运镜，占全片镜头数 50%-60%**；无情绪烘托、无叙事转折、无焦点引导的常规叙事画面；**唯一可无限连续使用的运镜** |
| 水平/垂直展示运镜 | 场景开始或收尾需展示两个及以上物体或人物时，用水平或垂直运镜**挨个展现**（如战斗开始前展示我方阵容）；起点=第一个被展示对象、终点=最后一个 |
| 拉近运镜 | **第一帧是大空间、逐渐聚焦到一个小细节**；用于连续细节展示镜头；起点=大空间、终点=被聚焦的小细节 |
| 拉远运镜 | **第一帧是细节特写、逐渐后拉展示整个空间**；用于场景更换后的开场、人物手拿关键道具时；起点=细节特写、终点=整个空间 |
| 环绕运镜 | 展示主角，或**通过环绕逐渐展现出旁边的人或事物**；适用范围与水平/垂直展示运镜类似 |
| 跟拍运镜 | **除固定机位外最常用**：只要画面里人物在移动或有动作即可用；运镜栏必须写明「跟拍运镜，焦点是谁」 |

> 运镜不是装饰。每种运镜只在本标准给出的 application 范围内合法；选运镜必须先问『本镜属于哪种叙事节拍』，再取对应运镜名——禁止按习惯、按顺手程度、或按上一批次的习惯把同一个运镜铺满全片。

> 违规判定：把某运镜用在适用范围之外的镜头即判定该镜不合格（needs_revision）。典型违规：给普通日常叙事镜配环绕运镜；给静态无动作人物配跟拍运镜；给非场景展示镜配水平/垂直展示运镜；不区分节拍、全片无差别铺同一种运镜；运镜栏未写明起点与终点。

- **运镜配比与反单一化·四条硬约束（v1.22.0）**：①**固定运镜占比必须落在 50%-60%**（强制校验，替代旧「固定≤30%」）；②单一运镜名（**固定运镜豁免本条**）占全片镜头数的比例 ≤ 40%；③相邻镜头连续使用同一运镜名不得超过 2 镜（**固定运镜豁免本条，可无限连续**）；④全片实际使用的运镜种类数 ≥ min(4, 全片有运镜字段的镜头数)。
- 为什么：全片只写一种运镜 = 镜头语言单调、画面节奏塌陷；而固定镜头过多又会让画面呆板。运镜必须随叙事节拍变化：常规叙事用固定运镜（占 50%-60%）、场景展示用水平/垂直展示运镜、细节聚焦用拉近运镜、场景开场用拉远运镜、人物与关系展示用环绕运镜、画面里人物有走动或动作时用跟拍运镜。
- 怎么查：统计全片『运镜方式』字段的：固定镜头占比（须 50%-60%）、单一运镜最高占比（固定豁免）、连续同运镜最长镜数（固定豁免）、运镜种类数；四项任一超限即本集不合格 needs_revision，统计明细必须写入 06-分镜/01-分镜管线/分镜总时长统计.json 的 camera_movement_ratio 块。
- ⚠️ ①与②③④互不替代：固定占比 50%-60% 只防『画面过飘/过呆』，防不住『全部动态镜头都是拉近运镜』这类单一化——四条必须同时满足；②③两条对固定运镜豁免，其余五类运镜照常受约束。

- H3 与通用分镜：每镜一个『运镜方式』字段（逐镜填写，并写明起点与终点）。seedance2.5：整组的运镜合并为组级唯一一条总体运镜（见 group_aggregate_camera_movement_rule），但**六类闭集**、适用范围、反单一化约束对组级总体运镜的每一段逐段同样适用（按每段归属的运镜类型统计）。

### 五、禁止自作主张（逐条核对，违反任一条该阶段判 failed）

- ⛔ 禁止自创镜头组类型名、禁止混搭组类型、禁止给场次 / 剧情段 / 段落冠以『镜头组』标题（只能用六类闭集）
- ⛔ 禁止自创运镜名、禁止写复合运镜名、禁止留空运镜字段、禁止用机位或景别顶替运镜
- ⛔ 禁止全片只写一种运镜、禁止把同一种运镜无差别铺满全片、禁止无视六类运镜各自的适用范围选运镜、禁止运镜栏不写起点与终点
- ⛔ 禁止全片只用一种组类型；禁止在同一组内混搭两种组类型或让一组承担多个叙事目的
- ⛔ 禁止自定组内镜数（镜数由「讲明白一件事」决定；正反打组上限=说话人数+长台词反应镜；战斗组 4-6 镜），禁止自创组内结构；禁止组内相邻两镜使用同一景别（正反打 / 连续整体展示 / 连续细节展示三类豁免）
- ⛔ 禁止增减 / 改名 / 调序 / 拆分 / 合并分镜字段；禁止省略景别字段；禁止『中近景』这类模糊混合表述
- ⛔ 禁止先写『场景与人物』再编画面内容；禁止把场景人物清单整抄进单镜本栏；禁止本栏漏 ID 或写入未入画人物
- ⛔ 禁止跳过场景转换的过渡镜位：每次大场景转换必须设一个过渡镜位，且**过渡镜位一律使用标准转场镜头**（v1.24.30 起不再分配无人物大空镜配额）；禁止转场镜后直接跳人物特写
- ⛔ 禁止把连续整体展示组用于普通日常场景切换；禁止『从小到大』组首镜不用小景别、『从大到小』组末镜不用小景别（v1.24.3：两类组**只要求首末构成总体趋势**，中间各镜允许回摆、穿插、往复，但**相邻两镜景别不得相同**始终为硬约束）
- ⛔ 禁止战斗组缺段 / 乱序 / 合并；禁止特效环节镜景别不是特写；禁止插入镜引入新叙事目的；禁止跨镜动作跳变（前镜蓄力、后镜已命中）
- ⛔ 禁止正反打组内出现双人同框或非当前说话人入镜；禁止正反打镜头数超过「该段说话人数 + 长台词反应镜数」；禁止说话人台词超 15 字却不补对方表情反应镜
- ⛔ 禁止特写镜头不写焦点标记；禁止焦点写成泛指（人物 / 道具 / 环境 / 表情）或多焦点并列；禁止焦点脱离画面视觉中心
- ⛔ 禁止用『内心很悲伤』『非常紧张』这类纯心理形容词代替可观察微动作；禁止大景别镜写瞳孔、眼角等极细微细节
- ⛔ 禁止有出场人物的镜头画面内容缺三要素（行动轨迹 / 动作细节 / 神态细节），缺任一项即不合格（v1.22.0）
- ⛔ 禁止在两种合法情形之外使用过肩机位：合法情形仅两种——①正反打中拍摄说话对方的表情反应镜头；②说话一方身份处于高位或正在释放压迫感（v1.22.0）
- ⛔ 禁止转场镜违规：禁止把转场镜拆成两镜、禁止自创第四类转场类型、禁止把转场镜当组类型使用（v1.22.0）
- ⛔ 禁止跳过组间细节镜：每一个镜头组收束之后必须有且仅有一个大特写细节镜（人物细节或场景细节），数量**恰好 = 组数 N（不少不多）**；禁止两组之间直接硬切、禁止用非大特写景别替代、禁止细节镜引入相邻两组之外的新人物/新场景/新道具（v1.24.21）
- ⛔ 禁止任何角色看向镜头 / 屏幕 / 观众（除该镜已标注用户授权并在阶段状态.json 记录 eye_contact_camera_authorized=true）
- ⛔ 禁止有台词镜不使用『XXX（固定声线丨语气）台词：[正文]』格式；禁止无台词镜保留台词项或写占位内容；禁止画面内容出现说话 / 台词 / 对白字眼；**语气不得空缺、不得写成『正常说』『平静地说』这类泛泛表述**——必须有信息量且可演（压着嗓子低声急问／咬着后槽牙一字一顿／强装镇定却微微发抖…）；语气只写在括号内且不得与固定声线文字设定混写（v1.24.31）
- ⛔ 禁止把 BGM、背景音乐、配乐写进分镜或 overall_soundscape
- ⛔ 禁止凭习惯默认用 H3 分镜（必须先读路由、按 video_engine 选唯一一套）

## ONE-SHOT 生成纪律（v1.24.20，P0）

**每个镜头的图片与视频，各自只准生成一次。任何模式、任何环节都不得自动重跑。**

- **禁止自动重提**：生成链路上不得出现 `for/while` 重试循环、多层重试嵌套、子进程重跑、后台自动补跑。
  提交失败（超时、502、网关抖动、读超时、轮询超时、任务 FAILED、参考图未消费）一律**即停**，把原因交导演，
  不得自动再发一次。
- **提交前必须去重**：查 `13-工作流文档/生成台账.json`，同一 `shot_id` + 媒（image/video）已有任一条提交记录
  就禁止再提交；并发时用文件锁 + 唯一 task 文件保证单一在途。
- **AI 觉得不好 ≠ 可以自己重跑**：自检或闸门复核发现风格不符、画质不佳、构图不对时，**必须停下来询问导演**
  「这一镜我不满意，是否需要授权重做（会产生一次新的付费生成）」，得到授权才可重做。
- **二次生成唯一入口**：导演逐镜显式授权，登记到 `13-工作流文档/阶段状态.json` 的
  `regeneration_authorizations`（一次一镜一媒，用完即止），登记完成才允许发起下一次。
- **批量先报备**：≥2 镜/资产的批量生成，开跑前把预计请求数（＝待生成数，**不含**任何重试系数）报给导演确认；
  运行期实际请求数超报备数即立即熔断并上报。

唯一真源：`standards/one_shot_generation_policy.json`。

## 人物朝向硬规则（v1.24.19，P0）

**人物永远不要正对镜头——身子和面部都不要对着镜头。** 凡画面中出现人物：

- **身体**：至少侧转或背向镜头，禁止正面全身、正面半身、身体正对着镜头。
- **面部**：至少偏转 30°（推荐 45°~120°）或完全不入画；禁止正脸直视镜头。
- **机位**：含人物的镜头**禁用『正面机位』**，改用『左 45° 侧面机位』『右 45° 侧面机位』『背影视角机位』，
  或仰视／俯视机位配合侧向体位。『正面机位』只允许用于无人物空镜与场景交代镜。
- **每镜必写朝向**：『画面内容』必须写明人物的身体朝向与面部朝向，推荐句式
  『她侧身对着画面外，半侧脸朝向街口，视线落在画面之外的巷子里』。
- 局部特写镜写到『面部不入画』即可；无人物空镜不适用；角色资产定妆照（三视图）不受本规则约束。
- 唯一豁免：该镜已写明『（用户要求：允许直视镜头）』并在阶段状态记录授权。

唯一真源：`standards/character_facing_policy.json`；stage4 由 `STG4-C19` 机检。
本规则同时作用于 **分镜卡 / 分镜图提示词 / 视频提示词**——图片与视频两条链都必须命中。

## 【v1.24.30 共同口径补充（三套分镜技能一致）】

### ① 单镜持续时长 = 4-7 秒（硬区间）
每一镜『持续时长』必须落在 **4-7 秒**之间，低于 4 秒或高于 7 秒一律不合格。
**上限 7 秒是「两层都卡」**：分镜卡『持续时长』≤7 秒，且提交给视频接口的 duration 也 ≤7 秒（余量往上取到 7 秒为止）。
有台词的镜头仍须满足 `dialogue_pacing_rule`（≥ ceil(台词字数÷5) 秒）；
**该式算出的时长若超过 7 秒，不得延长时长解决，必须拆镜**（台词分载到两镜或多镜，台词正文一字不改）。

### ② 场景转换过渡镜位 = 全部用转场镜
每次大场景转换必须设一个过渡镜位，且该镜位**一律使用标准转场镜头**（三类之一，单镜内完成新旧场景切换）。
**v1.24.30 起不再分配「无人物大空镜」配额**——不得用空镜充当场景转换的过渡镜位。
详见 `standards/transition_shot_system.json`。

### ③ 细节镜 = 每组一个，且按情绪选取
**每一个镜头组收束之后各配一个细节镜**（大特写，人物细节或场景细节），组数 N → 细节镜**恰好 N 个（不多不少）**，独立编号 `S0x_Dnn`；某一组塞两个、别的组没有，属配属错配，必须改归。
**选哪一个细节，唯一标准是情绪的镜头语言**：先定性本组叙事目的与情绪，再去
**细节钩子 ↔ 情绪映射技能**（`embedded_skills.detail_hook_emotion_map` / `skills/detail_hook_emotion_map.md`）里取同族钩子，
最后挑本组场景内真实存在、且能拍成一个大特写的那一个。
详见 `standards/group_gap_detail_shot_policy.json`。

### ④ 组内叙事三段式：前提 → 经过 → 结果（战斗组除外）
**每一组镜头必须讲完一件事的三段**：①前提（这件事为什么会发生：背景/原因/动机/触发条件，台词或画面交代皆可）
→ ②经过（这件事本身怎么发展）→ ③**结果（后果，或人物的反应）**。
**只拆「经过」而不交代前提与结果 = 不合格**。例：主角吐槽一件事，必须先有「为什么吐槽」（前提），
吐槽完必须补一个**被吐槽人的反应**镜（结果）。
**战斗组除外**（其「发动→特效→命中→反应」四环节已内建因果闭环）。
本规则对「标准镜头组」与「普通叙事组」一律适用，不设例外。
详见 `standards/group_story_arc_policy.json`。

## 【v1.24.31 共同口径补充（三套分镜技能一致）】

### ① 画面描述要详写，且详写有边界
- **神态不得只写情绪词**：近景/特写/大特写必须写到**五官怎么动**（眉峰上挑／眉心竖褶／眼睑收窄／瞳孔收缩／鼻翼翕动／嘴角一侧下拉／咬肌鼓起／喉结滚动）。情绪词（『愤怒』『悲伤』）只能作为补充说明跟在五官描写之后。
- **镜头内有几个人就挨个写每个人**：各自的动作 · 位置 · 神态至少各一处。禁止只写主角、禁止用合并句（『两人相视一笑』）替代逐人描述。
- **道具状态变化必须写清变化前 → 变化后**，并写明触发者或触发原因。
- ⚠️ **写详细 ≠ 写不入画的人或物**：画外人物、前情往事、心理活动、后续剧情、场外声音，一律不写进『画面内容』。

### ② 用词必须取自资产 ID 映射表
『画面内容』里的人、场景、道具一律用**正式名**（角色正式名（CHxx）／场景正式名（SCxx）／道具正式名（PRPxx））。
**禁止泛称替代**：那个女孩／那名男子／老人／少年／女子／年轻人／陌生人／众人……（导演原话：人物叫林晚，就不能写『那个女孩』）。
同一镜里首次出现必须用正式名；同镜多个同性别人物必须靠正式名区分，不得用『另一个人』『对方』含糊指代。

### ③ 写完分镜必须逐镜对照，禁止抽样
写完后**一镜不漏**地把『画面内容』与『场景与人物』栏对照：①画面几人 = 栏几人（同一批人）；②画面出现的人／场景／道具栏里都有；③栏里列的画面里都有线索。**任一不符当场改**，不得只改抽检到的几镜。

### ④ 说话语气必须写足
台词括号内的语气**不得空缺、不得泛泛**（禁『正常说』『平静地说』），要具体到可演（压着嗓子低声急问／咬着后槽牙一字一顿／强装镇定却微微发抖）。语气不得与固定声线文字设定混写。

### ⑤ 分镜图即场景参考（提交多参的口径）
**H3 与通用板块都把分镜图当场景参考**（构图／机位／空间结构／光影）：**场景资产图 @SCxx 不进 ref_image**，ref_image 只允许「人物 → 道具 → 分镜图」三类。
提交前**逐镜**按该镜『场景与人物』栏绑定多参：栏内人物 → `<Subject N>` + ref_image；栏内道具 → 道具资产图 + ref_image；场景由分镜图承担。**逐镜全量，不得抽样**。
（**seedance2.5 路线例外**：其多参 = 人物 → 场景 → 道具，不得含分镜图。）

详见 `standards/frame_description_detail_policy.json`。

## 【v1.24.32 共同口径补充：群像镜站位与景别-人数（三套分镜技能一致）】

> 导演 2026-10-16 指令：「如果一段剧情有很多人一起的群像，写分镜的时候先固定站位，
> 如果中景，全景，远景不要有单人镜头，旁边的人也要入镜。特写和近景可以是单人镜头，只有一个人或者没人入镜。」

**适用**：同一场景**在场人物 ≥2 人**的群像戏。

1. **先固定站位，再定景别**：群像戏必须先在场景开头按 `scene_blocking_policy.blocking_lock_rule`
   把**全员总体站位锁死**（参照物 + 每人方位），然后才逐镜决定景别与入镜人物。
   **禁止先设计单镜构图、再倒推站位。**
2. **中景 / 全景 / 远景 = 不得单人镜**：除焦点人物外，**按锁定站位站在旁边的人必须一并入镜**，
   并在『画面内容』里逐个写清他们各自在本镜做什么（动作 · 位置 · 神态）。
   **不许用中/全/远景拍只剩一个人的画面**——确需单人时改用**近景或特写**。
3. **近景 / 特写 / 大特写 = 允许单人镜**：可以只有 1 人入镜，也可以**无人入镜**（空镜）。
4. **人数上限仍生效**：单镜出镜人数仍 ≤3，所以**群像大景别的入镜人数是 2-3 人**；
   场景人数超过 3 时，用**多个大景别镜分批交代**（换角度／换焦点），不得为塞人而破上限。
5. **无人物大空镜不受本条约束**，但不得充当场景转换的过渡镜位。

机检：`STG4-C27`。真源：`standards/scene_blocking_policy.json → crowd_scene_shot_scale_rule`。
