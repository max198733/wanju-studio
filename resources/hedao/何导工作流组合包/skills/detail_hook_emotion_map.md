# 细节钩子 ↔ 情绪映射技能

> 技能键：`embedded_skills.detail_hook_emotion_map`　|　来源：何导工作流 v1.24.34
> 调用时机：**需要时才加载本文件**；工作流骨架只保留指针，不内联本文件正文。
> 适用环节：stage4 拆分镜——**为每一个镜头组选定它的那个细节镜**（见 `standards/group_gap_detail_shot_policy.json`）。

## 1. 一句话定义

细节镜（insert shot / 插入镜）**不是「随便补一个特写凑时长」**，而是——
**用画面里的一件小事，替观众把这一组镜头想说、却没说出口的情绪说出来。**

电影语言里，细节镜是「情绪的原子」：它把观众的目光按导演的意图钉在一处，
让观众在还没来得及判断之前就已经被引导到该感受的位置上。

## 2. 唯一选取判据：三步法 + 三问

**三步法**

1. **定性** —— 读完本组全部镜头，用一句话写下本组的叙事目的与情绪。
   例：`本组＝主角得知亲人离世，站在灶台前 → 情绪：悲恸，且是「还没反应过来」的那种钝痛`。
2. **选族** —— 在 §3 情绪族表里找到同族（没有完全同族的，取最近的一族，并在分镜卡叙事目的里写明）。
3. **落地** —— 从该族候选钩子里，挑出**本组场景内真实存在、且能拍成一个 2-4 秒大特写**的那一个。

**三问（全过才可用，有一问不过就换下一个候选）**

| 问 | 内容 | 不过就换 |
|---|---|---|
| 一、服帖吗 | 它说的情绪，是不是就是本组想表达的那个情绪？（不能偏、不能弱） | 换族或换钩子 |
| 二、在场吗 | 它在本组已出现的场景 / 人物里真实存在吗？（禁止凭空引入新人物、新场景、新道具） | 换钩子 |
| 三、能拍吗 | 它能写成一个**具体可见的状态**（不是抽象概念、不是心理解释）吗？ | 换成可拍摄的物或身体痕迹 |

> 反面例：本组情绪是「悲恸」，写出 `焦点：他内心的崩溃` —— **第三问不过**，因为「内心崩溃」拍不出来。
> 正面例：改写成 `焦点：他握着汤勺的手停在半空，指节泛白，勺里的汤晃出一圈涟漪` —— 三问全过。

## 3. 情绪族 × 细节钩子库

> 用法：**先定位情绪族，再在「场景钩子 / 人物钩子」两栏里各挑 1-3 个候选，最后按三问选定 1 个。**
> 同一场戏里同一个钩子只用一次；前后相邻的细节镜不得重复同一对象。

### 3.1 悲恸 / 离别 / 死亡
- **情绪内核**：温度骤降、不可逆、来不及
- **场景钩子**：烛火被风压偏并熄灭；雨砸在地面溅起泥点；香灰断落；白布一角垂落；纸钱烧到最后一点红；灶上白汽散掉；灵前的油灯忽然跳了一下
- **人物钩子**：手指僵在对方衣袖上；喉结上下滚了一下；下巴压出颤；指甲掐进掌心；衣襟被攥出一道折痕
- **光影倾向**：冷调、单点光源、明暗对比大
- **避坑**：不要「泪流满面」的大哭特写——那是**外放**情绪，不是细节；要用「忍不住又忍住」的身体痕迹

### 3.2 思念 / 怀念
- **情绪内核**：停在那里、时间错位、还有余温
- **场景钩子**：茶杯还留着半杯凉茶；雨在窗玻璃上流下的水痕；旧照片边角翘起；门帘轻轻晃；桌上多摆了一副没人用的碗筷；墙上挂钟停在某个时刻
- **人物钩子**：指尖摩挲旧物上的裂痕；无意识转动手上的戒指；对着空椅子停了半秒的目光
- **光影倾向**：暖调回忆光与冷调现实光对切（匹配插入 / 不匹配插入的经典用法）
- **避坑**：不要写「他想起往事」——要写**引起回忆的那个物**

### 3.3 喜悦 / 温暖 / 释然
- **情绪内核**：松开、变亮、轻
- **场景钩子**：锅盖被蒸汽顶起又落下；糖块在热茶里化开的漩涡；窗缝漏进来的一束光落在地面；院子里晾着的衣服被风吹鼓；两只碗轻轻碰在一起
- **人物钩子**：嘴角压不住地往上提又抿住；指尖在桌面上轻敲了两下；肩膀终于松下来
- **光影倾向**：暖调、高亮、光比柔和
- **避坑**：不要用大笑特写；喜悦的细节贵在「没忍住」

### 3.4 愤怒 / 压抑
- **情绪内核**：向内收的火、蓄势
- **场景钩子**：茶盏被放下时磕出的一声；桌面上的水痕被手指抹开；门框被掌根撑住；帘子被人攥住一角
- **人物钩子**：太阳穴一跳；咬肌鼓起；指节抵在桌沿发白；把话咽回去时喉头动了一下
- **光影倾向**：侧逆光、硬光、压暗背景
- **避坑**：愤怒的细节**要压制**，一旦放出来就变成外放情绪镜，不再是小细节

### 3.5 恐惧 / 不安 / 预感
- **情绪内核**：收紧、失重、被注视
- **场景钩子**：门缝下移过去的一道影子；油灯忽然爆了一下灯花；风把窗纸吹得往里凹；水缸里的水面无风起波
- **人物钩子**：睫毛一颤；指尖掐住衣角；后退半步时脚跟先落地；吞咽的声音被放大
- **光影倾向**：大面积暗部 + 小块高光（不匹配插入最有效）
- **避坑**：不要直接给「怪物」——**给线索，不给答案**

### 3.6 孤独 / 疏离
- **情绪内核**：空、远、没有被回应
- **场景钩子**：两副碗筷只有一副被用过；院子里的水缸结了一层薄冰；门槛上的脚印只有一行；饭桌上的菜早就凉了
- **人物钩子**：抬起的手又放下；回头看了一眼门口却没人在；手指反复摩擦碗沿
- **光影倾向**：冷调、空旷、大留白
- **避坑**：不要用「一个人站在大远景」——那是**大空镜**不是细节镜；细节镜必须是大特写

### 3.7 决绝 / 意志 / 抉择
- **情绪内核**：切断、落定、不再回头
- **场景钩子**：绳子被一刀截断；印章按在纸上留下重印；信被投进火盆卷起边；门被从里面闩上
- **人物钩子**：握剑的手慢慢收紧；把符纸折好塞进怀里；深吸一口气后肩背挺直
- **光影倾向**：硬光、高对比、单一强光源
- **避坑**：要写「切断」的那一瞬，不要写切断之后的抒情

### 3.8 屈辱 / 隐忍
- **情绪内核**：被迫低头、咽下去、表面平静
- **场景钩子**：鞋被踏在泥里；跪下的那一处地面被压出痕；赏钱被丢在地上滚了两圈
- **人物钩子**：垂在身侧的手不停发抖；额角渗出的汗顺着鬓边滑下去；嘴唇被咬出一线白
- **光影倾向**：俯拍视向的暗压、顶光
- **避坑**：不要写「他很屈辱」；要写**屈辱在身体上留下的痕迹**

### 3.9 爱意 / 暧昧
- **情绪内核**：靠近、犹豫、不敢确认
- **场景钩子**：两个人之间逐渐缩短的茶盏距离；递过去的手绢停在一半；灯花被人轻轻剪了一下
- **人物钩子**：指尖碰到又缩回；目光在对方唇上停了半秒又移开；耳根一点点红上去
- **光影倾向**：暖调、柔光、浅焦
- **避坑**：不要写对视——**写没敢对视**

### 3.10 荒诞 / 黑色幽默
- **情绪内核**：错位、越正经越好笑
- **场景钩子**：锣鼓敲得极响而院里空无一人；欠条被郑重其事地裱起来；供桌上摆着不合时宜的物件
- **人物钩子**：一本正经地把荒唐事做完；动作标准得像在演礼
- **光影倾向**：正常打光 + 荒谬内容（**反差即笑点**，不要刻意打喜剧光）
- **避坑**：荒诞靠**信息错位**而非夸张表演

## 4. 两种插法：决定这个细节是「顺」还是「刺」

| 类型 | 做法 | 效果 | 用于 |
|---|---|---|---|
| **匹配插入** | 与被插入处主镜的光线、氛围、色调一致 | 无缝、自然，感觉是场景的一部分 | 情绪**延续**、回忆、写实感 |
| **不匹配插入** | 光线或氛围明显偏离主镜（更暗、色偏、过曝） | 突兀、有压迫感，风格化 | 情绪**断裂**、危险预警、反转前兆 |

## 5. 快速插入（连切）

把 2-3 个细节以极短时长连续切出（每个约 0.5-1 秒），用来表现**强烈情绪或混乱**。
本工作流单镜区间为 4-7 秒，因此连切需在**拆镜层面**实现：
把它写成同一组内的多镜，并在分镜卡叙事目的里说明这是「快速插入」手法。
（若项目允许更短镜，按项目实际口径执行，并在自检中记录。）

## 6. 与工作流其他规则的接缝

| 接缝 | 约束 |
|---|---|
| 景别 | 细节镜**固定为大特写**（不得用近景及以上替代） |
| 数量 | **每组一个**，组数 N → N 个（见 `group_gap_detail_shot_policy`） |
| 位置 | 默认落在**本组收束之后**；导演可自由调位（数量硬校验、位置仅 WARNING） |
| 编号 | 独立编号 `S0x_Dnn`，不占用组内 `S0x_NN` |
| 标记 | 『画面内容』开头写 `组间细节镜：[人物细节|场景细节]｜` + `焦点：[对象]（[具体可见状态]）` |
| 朝向 | 含人物面部/肢体者仍受 `character_facing_policy` 约束；纯场景细节不受朝向与眼神落点约束 |
| 时长 | 一般 2-4 秒，且仍在单镜 4-7 秒硬区间内 |
| 参考图 | 人物细节须绑该角色参考图、场景细节须绑该场景参考图 |

## 7. 禁忌

- ⛔ 选**抽象概念**（「孤独」「崩溃」「绝望」）——必须落成画面内可见的物或身体状态
- ⛔ 选本组**不存在**的人 / 景 / 道具
- ⛔ 把情绪**直白写成表情**（写「他很伤心」）——要写身体痕迹（写「指甲掐进掌心」）
- ⛔ 细节镜用**近景及以上**景别
- ⛔ 前后相邻细节镜**重复同一对象**（同一场戏同一钩子只用一次）
- ⛔ 连续多个细节镜表达**同一情绪**（除非明确使用 §5 快速插入手法）
- ⛔ 用**大空镜**顶替细节镜
- ⛔ 细节镜与**本组叙事目的情绪不对应**（随便挑个物件凑数）

## 8. 完整示例

**输入**：本组 ＝ 主角得知亲人离世，独自站在灶台前把汤盛出来，动作照常但慢了半拍。叙事目的：表现「还没反应过来的钝痛」。

**三步法**：①定性 → 情绪族 3.1 悲恸 / 离别；②选族 → 3.1；③落地 → 场景钩子候选：灶上白汽散掉 / 烛火熄灭 / 雨砸地面；人物钩子候选：手握汤勺停在半空 / 喉结滚动 / 下巴压出颤。

**三问**：白汽散掉 → 服帖✓ 在场✓ 能拍✓（选定）。

**输出**：

```
组间细节镜：场景细节｜焦点：灶上汤锅边缘溢出的一缕白汽（被灶火烘得歪向一侧，随后无声散掉）｜
运镜方式：固定运镜
音效：灶火的轻响，柴火偶尔的爆裂声
```

**为什么不是「他流泪」**：流泪是外放情绪，观众看到的是结果；
白汽散掉是**情绪的替身**——它什么都没说，但观众自己会把「失去」这两个字放进去。
