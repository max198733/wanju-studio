### ① 站位与朝向双锁定（`scene_blocking_policy.facing_lock_rule`）

- 场景开头锁死全员总体站位时，**必须同步锁定朝向**：逐人写明「身体朝向 + 面部朝向 + 视线落点」，随场景人物清单登记 `facing_state`。此后同场景同一人的朝向即为锁定值。
- **不得擅动**：未写转身动作的镜头，朝向所指方向必须与锁定值一致。允许因机位/景别不同改变**可见角度**（正打看左脸、反打看右脸），但不得改变人物在场景中面朝哪边。
- **转必须写**：需要转身时，必须在该镜『画面内容』写出转身的起止动作，下一镜沿用新朝向并整体更新全员朝向（视同走动更新）。
- **禁换面换朝向**：正反打只改拍摄方向，不改人物在场景中的朝向与左右关系。
- 机检：`STG4-C28`（无转身标记却改变朝向 = 朝向漂移 FAIL）。

### ② 逐镜入画名单显式声明（`scene_character_roster_policy.per_shot_presence_declaration_rule`）

- 该场景在场 ≥2 人时，**每一镜『画面内容』开头必须先写入画名单**：`画面内只有X一人` / `画面内只有X、Y两人` / `画面内只有X、Y、Z三人`（人名，不用「她/他们」）。
- 声明句的人物集合必须与该镜『场景与人物』栏**逐字对应**（同人数、同身份、同顺序）。
- **全景/远景必含在场者**：该时刻在场的有名角色一个不得缺席；超过单镜 ≤3 人上限时拆镜，不得靠裁人解决。
- 中景至少含焦点人物 + 直接交流对象；近景/特写允许单人（其余人按锁定站位留在画外原位）。
- 在场者缺席但无离场交代 = **凭空消失 FAIL**。机检：`STG4-C29`。

### ③ 跨镜动作接力显式继承（`continuity_policy.action_handoff_rule`）

- 同一动作跨两镜及以上延续（对峙姿势/擦枪/举枪/走路/握手/捻佛珠等），后续镜必须写：
  `保持与上一镜一样的姿态——左手向前伸直、掌心朝外，右手向后上方抬起，右脚抬在左腿上`。
- **只写「姿态不变」「姿势照旧」不算合规**：必须复述手在哪、脚在哪、重心在哪、朝向何方。
- 上一镜的 `after_state` 即本镜起始状态，不得矛盾；同一动作跨镜超 3 镜，每 3 镜用中景/全景复述一次完整姿态。
- 机检：`STG4-C30`（缺继承句记 WARNING，状态矛盾记 P1）。

### 生成并发口径（v1.24.29，P0）

- **按批次任务数一次全部提交**，每 5 个一组、组数不限量；**禁止写死「并行度 = 5」**。
  并发数 = 本次任务数（沙箱上限内），可用环境变量 `GEN_CONCURRENCY` 覆盖。
- **时效硬指标：一批生成最多 20 分钟必须出完。** 超时先查并行度是否开够，**不得归因于「模型慢」**。
- 必须用线程池（`concurrent.futures.ThreadPoolExecutor`），禁止 for 循环内同步等待（那是串行）。
- 与 ONE-SHOT（`standards/one_shot_generation_policy.json`）并行生效：
  **同一 `shot_id` 不得并发多路**，但**不同 shot_id / 不同资产之间全量并行完全合规**。
- 配套强制：① 台账/索引 JSON 的读-改-写加线程锁（并发写会互相覆盖、丢 task_id 后无法恢复）；
  ② 进度输出 flush 或 `-u`（否则重定向日志时被缓冲）；③ 生成器三态：已有产物跳过 → 在途则轮询恢复绝不重发 → 无记录才提交。

## 组内叙事三段式（v1.24.30，P0）

> 真源 `standards/group_story_arc_policy.json`（rule_id `GSARC-1`）。导演 2026-10-15 指令：
> 「一件事发生有前提（背景，原因），经过，结果（或者是人物的反应），你一组镜头必须包含这三个点，
> 你现在拆的分镜经常只有经过……除了战斗组，其他不论是我技能里的标准镜头组，还是普通的叙事组都需要遵循这个规则。」

- **三段齐全**：每组必须讲完一件事的 ①**前提**（为什么会发生：背景/原因/动机/触发条件）→ ②**经过** → ③**结果**（后果，或**人物的反应**）。

## 细节钩子 ↔ 情绪映射技能（v1.24.30 新增）

> 技能键 `embedded_skills.detail_hook_emotion_map`，文件 `skills/detail_hook_emotion_map.md`。

- **定位**：细节镜（insert shot）不是「补一个特写凑时长」，而是**用画面里的一件小事，替观众把本组想说没说出口的情绪说出来**。
- **唯一判据：三步法 + 三问**。三步法＝定性本组情绪 → 取同族候选钩子 → 落地选定一个；
  三问＝**服帖吗 / 在场吗 / 能拍吗**（有一问不过就换候选，不得硬凑）。

## 画面描述详写与多参一致性（v1.24.31，P0）

> 真源 `standards/frame_description_detail_policy.json`（rule_id `FDDP-1`）。导演 2026-10-15 第二批指令。

### ① 神态必须写到五官怎么动
**不得只写情绪词**（『愤怒』『悲伤』『惊讶』）。近景/特写/大特写必须写成**可观察的肌肉／五官动作**：
眉峰上挑 · 眉心挤出竖褶 · 眼睑收窄 · 瞳孔收缩 · 眼睫连颤 · 鼻翼翕动 · 鼻尖发红 · 下唇内收 · 嘴角一侧下拉 ·
咬肌鼓起 · 下颌绷紧 · 喉结上下滚动 · 眼眶泛红 · 太阳穴一跳 · 额角渗汗。
情绪词只能作为**补充说明**跟在五官描写之后（`眉心挤成竖褶、咬肌鼓起——他在压着火`），不得替代五官描写。

### ② 镜内有几个人就挨个写每个人
每个人在本镜内的 **动作 · 位置 · 神态** 至少各有一处描写。**禁止**只写主角、其余一笔带过（『另两人站在一旁』）；
**禁止**用合并句替代逐人描述（不许用『两人相视一笑』代替分别写 A 与 B）。
**道具发生状态变化必须写清「变化前 → 变化后」**并写明触发者（杯子被搁下磕出响、烛火被风压偏并熄灭、纸张被撕成两半）。

### ③ ⚠️ 写详细 ≠ 写不入画的人或物
详细只加在**本镜画面内实际可见**的人、场景、道具上。**画外人物、前情往事、心理活动、后续剧情、场外声音**
一律不写进『画面内容』（心理活动由神态与动作外化；场外声只进『音效』字段）。

### ④ 用词必须取自资产 ID 映射表
人、场景、道具一律用**正式名**（角色正式名（CHxx）／场景正式名（SCxx）／道具正式名（PRPxx））。
**禁止泛称替代**：那个女孩／那名男子／老人／年轻人／陌生人／众人……（导演原话：人物叫林晚，就不能写『那个女孩』）。
同镜首次出现必须用正式名；同镜多个同性别人物必须靠正式名区分，不得用『另一个人』『对方』含糊指代。

### ⑤ 写完分镜必须逐镜对照，禁止抽样
**一镜不漏**核对『画面内容』与『场景与人物』栏：①**画面几人 = 栏几人**（同一批人，不多写不漏写不写未入画）；
②画面出现的人／场景／道具栏里都有；③栏里列的画面里都有线索。任一不符**当场改**，不得只改抽检到的几镜。

### ⑥ 说话语气必须写足
台词括号内语气**不得空缺、不得泛泛**（禁『正常说』『平静地说』『一般语气』），须具体到可演：
压着嗓子低声急问／咬着后槽牙一字一顿／强装镇定却微微发抖／带着哭腔却硬撑／冷笑着从鼻子里哼出来。
语气只写在括号内，不得与固定声线文字设定混写。

### ⑦ 分镜图即场景参考（H3 与通用板块）
**H3 与通用板块（wan3.0 / grok / seedance2.0）都把分镜图当作场景参考**（构图／机位／空间结构／光影）：
**场景资产图 @SCxx 不得进入 ref_image**，ref_image 只允许「人物 → 道具 → 分镜图」三类（分镜图固定末位）。
提交前**逐镜全量（不抽样）**按该镜『场景与人物』栏绑定多参：栏内人物 → `<Subject N>` + ref_image；
栏内道具 → 道具资产图 + ref_image；场景由分镜图承担；栏内没有的一律不得参考。
（**seedance2.5 路线例外**：多参 = 人物 → 场景 → 道具，不得含分镜图。）

## 群像镜站位与景别-人数（v1.24.32，P0）

> 真源 `standards/scene_blocking_policy.json → crowd_scene_shot_scale_rule`。导演 2026-10-16 指令：

**适用**：同一场景**在场人物 ≥2 人**的群像戏。

| 景别 | 能否是单人镜 | 要求 |
|---|---|---|
| **中景 / 全景 / 远景** | ❌ **不得单人镜** | 除焦点人物外，按锁定站位站在旁边的人**必须一并入镜**，并逐个写清各自在本镜的动作·位置·神态 |

  场景人数超过 3 时，用**多个大景别镜分批交代**（换角度／换焦点），不得为塞人而破上限。
