# M3 文字建筑（口播金句专用）

- 分类：M 动态风格 · 文字和金句类
- 长什么样：只用文字。每个词有一个"结构上的角色"：有的是梁，有的是柱子，有的是地板。前面的词搭起来，最后一句话"站"在前面搭好的东西上。
- 适合：结尾金句"学习，相信自己"。全片最值得做的一段。

## 风格提示词

做一段 [20] 秒、只用文字的口播动画。台词按顺序是：[第1句]、[第2句]……每个关键词有一个结构上的角色，比如"学习"是地基，"相信"是柱子，"自己"是站在上面的人。文字用真实的字形轮廓搭出来，每一句都改变画面的结构。最后一句必须"站"在前面那些词搭好的东西上。配色：深色背景、纸色字、一个强调色。不要麦克风、人群、旗子这类俗套画面，不要素材视频。做完挑 8 帧检查，读起来顺序对，最后的平台确实是前面的元素搭起来的。

## 用这一种做片

- 上面 `{{ }}` 里是要你填的内容；填掉它，保住形成这个风格的核心视觉特征（配色、运动节奏、构图逻辑）。
- 画面是时间 t 的纯函数：同一个 t 每次画出来一样。随机数固定种子，不要用 `Math.random`，不要在帧之间累积状态。
- 一般用原生 HTML + Canvas／SVG／CSS；需要复杂空间镜头时才引 Three.js。一个页面没有声音。
- 用户给的数字、事实、品牌原样用，不编造；图表形状要跟数值对得上。
- 成品留在项目里，文字、颜色、节奏都要能再改：常改的参数集中在一处。
- 做完打开看首帧、中段、尾帧：字体、溢出、黑帧、字幕可读性。用户要 MP4 就真渲染，缺依赖就说清没导出。
